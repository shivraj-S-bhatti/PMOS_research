# Data

Raw Kaggle files are not committed to this repository.

The analysis script downloads the public Kaggle dataset automatically with
`kagglehub` and stores the workbook locally under `data/raw/`, which is ignored
by git:

https://www.kaggle.com/datasets/prasoonkottarathil/polycystic-ovary-syndrome-pcos

Primary workbook used:

- `PCOS_data_without_infertility.xlsx`, sheet `Full_new`
